# Google Business Profile Audit Proposal Tool

Standalone client proposal tool. It contains only:

- Business details form
- 30-point public Google Business Profile audit checklist
- Weighted GBP Profile Quality Score based on public checks
- Public Google Maps / GBP link saved with each proposal
- Evidence and notes fields
- Automatic score and opportunity summary
- Professional client-facing proposal preview
- Browser print-to-PDF export

No Google Maps search, lead database, API key or old GMB Audit Hub workflow is included.
The public link opens the profile for review; the tool does not claim access to owner-only Google insights.

## Deploy

Upload the contents of this folder to a new GitHub repository and connect that repository to Netlify. The site is a static HTML/CSS/JavaScript tool and needs no build command.
